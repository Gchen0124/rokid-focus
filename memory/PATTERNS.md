# Patterns

updated: 2026-08-17

Repeating rules. Promote from day files. Align with daily-review **Never** / **Carry On** when a review names one.

## Carry On

- Laptop is the cockpit; glasses only glance. Edit name / $ / minutes / Done on the Mac.
- Save on every committed change; USB-push if the glasses are plugged in. No live model.
- Rank in conversation, then write the file. The Open list *is* the decision.
- HUD stays `# · EV · time · title`. Drop chrome that does not change a glance.
- Size rows by value so the top bet is physically larger.

## Never

- Do not auto-call an LLM on every keystroke (token-heavy and usually wrong).
- Do not put a chatbot or ranking essay on the waveguide.
- Do not let a formula silently override a pin we just agreed.
- Do not start a second source of truth (Reminders / Notion / phone APK) without an explicit sync design. Reminders stay optional.
- Do not relaunch product scope (voice/TTS, Hi Rokid hijack) during a priority day.

## Still forming

- `dl` in a title currently means “at least today.” Confirm before treating it as `now`.
- $0 EOD tasks (`bunny`) are real work; they should not outrank EV, but they should not vanish from the evening pass.
