## How this research was done (read this first)

Yesterday’s hunt and this calendar used the same method. It is **not** “Grok memory of 2025.” Every dated claim is supposed to come from a live page.

### Tools actually used

| Tool | What it is | Used for |
|---|---|---|
| **Tavily** (MCP `tavily_search` + `tavily_extract`) | Paid search + page extract | First pass on incubators, angels, hackathons; pulling apply-page text |
| **WebSearch** | Google-style search | Named programs + year + “application deadline” |
| **WebFetch** | Open a specific URL | Official apply pages: YC, SkyDeck, EF, HF0, TiE Women, Activate, PearX, a16z speedrun, 500 Flagship, CES awards, GESA, AWE |
| **Notion MCP** | Your `funding sources` DB | What we already stored, overdue `reschedule at？`, High rows |
| **X / YouTube / newsletters** | Org channels listed in `CHANNELS.md` | Confirm “apply / batch / deadline” posts. grok-search MCP key was **unset**, so we did **not** use Grok’s X search. Did not burn the X API quota. |

Not used this pass (available later if we need them): Chrome DevTools / Firecrawl for JS-only pages, Hacker News, Reddit, Product Hunt, YouTube transcripts, Xiaohongshu.

### How a date gets written

1. Seed official sources (YC apply, SkyDeck apply, `apply.joinef.com`, `speedrun.a16z.com`, `activate.org/apply`, `awexr.com`, `ces.tech`, `tiewomen.org`, `pear.vc`, `betaworks.com/camp`).
2. Search `"[org] [program] 2026 OR 2027 application deadline"`.
3. **Open the official page.** A listicle (Zyner, Peony, Slidebean, Instagram recap) can only create a *watch date*.
4. Write Apply open / Apply close / program run separately. Never put the cohort dates in the deadline column.
5. If the official page is silent, write the **historical cycle** and a Next-check alarm 6–8 weeks before last year’s open.

That is why some 2026 windows felt “suddenly closed”: the Notion DB stored prose (`Timeline`) and a text `reschedule at？`, not real Apply-close dates, and many checks were already overdue. The miss is a **clock problem**, not a missing-website problem.

### What we will not do from a listicle

- Invent a 2027 YC on-time deadline. YC has not published W27/P27/S27 cutoffs. Early Decision for a batch *after* Fall 2026 is live on the official apply page.
- Treat “500 Flagship closes Oct 11” as gospel without a second look — the same page still shows stale 2024/2025 chrome. Flagged below.
